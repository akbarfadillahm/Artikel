🚀 Fokus & Ketertarikan Teknologi

Di dunia software engineering, saya menaruh minat besar pada dua pilar utama:

Data Science & Machine Learning

Saya sangat tertarik pada bagaimana data bisa diubah menjadi keputusan yang cerdas. Beberapa algoritma dan model yang sering saya ulik dan terapkan dalam proyek akademis maupun eksperimen pribadi meliputi K-Nearest Neighbors (KNN) yang merupakan salah satu algoritma klasifikasi favorit saya dengan penerapan sangat luas, Convolutional Neural Networks (CNN) untuk eksplorasi di bidang Computer Vision, serta Long Short-Term Memory (LSTM) untuk menangani data sekuensial dan prediksi berbasis waktu.

Full-Stack Web Development

Selain kecerdasan buatan, saya suka membangun antarmuka yang interaktif dan sistem di balik layar yang kokoh. Tech stack yang biasa saya gunakan meliputi HTML, CSS, JavaScript, dan React untuk bagian Front-End, serta Laravel (PHP) dan Java Swing untuk pengembangan aplikasi desktop di bagian Back-End.

Pengalaman & Proyek Nyata

Saya percaya bahwa teori terbaik adalah teori yang dipraktikkan. Beberapa pengalaman dan proyek yang telah saya kerjakan antara lain terlibat dalam tim universitas untuk merancang dan membangun Sistem Inventaris Perpustakaan (Program PKM) guna digitalisasi perpustakaan. Selain itu, saya juga mengembangkan Otomatisasi Sistem Rekrutmen (Kerja Praktek) berupa sistem penyaringan rekrutmen otomatis menggunakan algoritma K-Nearest Neighbors (KNN) yang diimplementasikan langsung untuk kebutuhan operasional bisnis.
